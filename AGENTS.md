# AGENTS.md

## General Instructions

- This project is a website built with Vite and React.
- There is no backend.
- Keep the project focused on frontend code, content, and styling.
- Prefer simple, maintainable components and clear file organization.

## Project Overview

- This is a website for the company "DevelopersLab".
- DevelopersLab focuses on educating people about modern technologies, especially AI.
- The company offers free classes that last about 3-4 hours.
- Each class is designed for groups of around 30 people.

## Development Notes

- Use React components for reusable UI sections.
- Keep copy clear, concise, and beginner-friendly.
- Do not add backend logic, databases, authentication, or server-side features unless explicitly requested.

## Visual Style

- When creating the application UI, use the color palette from the DevelopersLab Montenegro website.
- The current palette source is the official site: https://developers-lab.me/
- Use the palette consistently and decide how to combine the colors based on the section, hierarchy, and interaction state.
- Prefer a clean educational/technology look: bright backgrounds, dark readable text, and warm accent colors for calls to action.

### DevelopersLab Palette

- White: `#ffffff`
- Soft background: `#f9f9fb`
- Light section background: `#f2f3f5`
- Border/subtle divider: `#e2e2e2`
- Primary accent/orange: `#f9ae3b`
- Text gray: `#4a4e57`
- Dark text: `#292929`
- Deep navy: `#212934`
- Success/active green: `#65bc7b`
- Muted gray: `#9ea0a4`
- Secondary accent/purple: `#6e45a1`

### Color Usage Guidance

- Use `#ffffff`, `#f9f9fb`, and `#f2f3f5` for page backgrounds and section separation.
- Use `#212934`, `#292929`, and `#4a4e57` for headings, body text, navigation, and footer areas.
- Use `#f9ae3b` for primary buttons, important links, highlights, and key calls to action.
- Use `#65bc7b` for active/success states, available course labels, and positive status indicators.
- Use `#6e45a1` sparingly for secondary emphasis, badges, or visual contrast.
- Always maintain readable contrast and avoid inventing unrelated color palettes unless explicitly requested.
